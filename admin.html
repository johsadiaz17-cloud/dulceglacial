🍦 Panel de Administración

Administra sabores y disponibilidad de productos

📌 Cómo actualizar los sabores:
1. Cambia los sabores arriba
2. Clic en "Generar código"
3. Clic en "Copiar código"
4. Ve a GitHub → sabores.js → ✏️ Editar
5. Ctrl+A y pega el nuevo código
6. Commit changes ✅

Marca los productos que estén AGOTADOS

📌 Cómo actualizar los agotados:
1. Activa/desactiva los productos arriba (verde = disponible, rojo = agotado)
2. Clic en "Generar código"
3. Clic en "Copiar código"
4. Ve a GitHub → disponibilidad.js → ✏️ Editar
5. Ctrl+A y pega el nuevo código
6. Commit changes ✅
